I'm just a happy programmer that likes to hack stuff. I'm Randall Degges, and today I'm VP of AI Engineering at [Snyk](https://snyk.io).

I've been writing software since I was 12, and this site is where I write about it -- programming, security, developer tools, and whatever I've been experimenting with lately. Sometimes that's a rant about local storage or JSON Web Tokens. Sometimes it's a more personal experiment, like whether music actually helps me focus, how I use journaling, or how much electricity my laptop is burning.

{{< clear >}}

What I enjoy most is building things that other programmers actually want to use. Elegant developer services, documentation that doesn't make you want to close the tab, SDKs that feel obvious. I like teaching that stuff too, especially web authentication and cryptography, and I've been writing here (on and off) for a long time.

These days I spend a lot of my time architecting agents and automations, experimenting with AI, and trying to build the highest quality products humanly possible.

I joined Snyk in 2021 to lead developer and security relations, and moved into my current role in 2025. I also advise a couple of developer-focused companies -- mainly [WorkOS](https://workos.com) and [Arcade.dev](https://www.arcade.dev) -- on developer relations, content, and how they show up for programmers. I used to do the same kind of advisory work at [Onehouse](https://www.onehouse.ai) and [Builder.io](https://www.builder.io). I also formerly helped [Ragie](https://www.ragie.ai), until Ticketmaster acquired them in 2026, and StepZen, until IBM acquired them in 2023.

Before Snyk I spent about four years at Okta leading developer advocacy, and before that I was the first developer evangelist at Stormpath, where I helped build the libraries, docs, and community around a developer authentication service.

Earlier on I was CTO at Telephony Research Services in Los Angeles. I wore a lot of hats there: I helped build and grow OpenCNAM (a caller ID API for developers), worked on telephony and teleconferencing systems, and learned a lot about shipping and marketing products myself. Before that I was a lead professional services engineer at Fonality, working on Trixbox CE -- an open-source Linux distribution, built on Asterisk, that businesses used to run their phone systems.

A lot of my favorite work has been open source or free for developers to use. I built [ipify](https://ipify.org), a reverse-IP API that millions of applications have relied on. I wrote PassProtect, a library and browser extension that warns you if a password you're typing has shown up in a breach (powered by [Have I Been Pwned](https://haveibeenpwned.com/)). I built [postgression](/2013/postgression-a-postgresql-database-for-every-test-case/) to provision a real PostgreSQL database for your tests, so you don't have to run and babysit a local server. At Stormpath I wrote security libraries in Python, Node, and Go, and in 2012 I published [*The Heroku Hacker's Guide*](/2012/my-heroku-book-is-finished/).

I started a computer science degree at UC Santa Cruz in 2006. I was a terrible student and dropped out after two years. Almost everything I know about programming I taught myself.
