{{- /* Image render hook. Page-bundle images get a responsive srcset and, when it pays, a WebP alongside a JPEG or PNG fallback. Format is not guessed from the pixels: a lossy re-encode of a screenshot on this site scored 59 on SSIMULACRA2, which is visibly damaged text, while the same setting is fine on a photo. Authors set the resource param `kind` to photo, screenshot, or illustration. With no kind, a JPEG is a photo and anything else (PNG) takes the lossless path. Photos are lossy WebP at q85, the same fidelity as the JPEG derivatives, with a JPEG so a feed or mail client that ignores still gets a real image. Screenshots and illustrations keep a PNG , and a lossless WebP is emitted only when every candidate is smaller than that PNG. A partial WebP srcset would make a browser upscale the small file instead of using the PNG. Derivatives are published under /img/. Their filenames carry Hugo's processing hash (_hu_), which is what makes the one-year immutable cache header honest. The original stays at its page-bundle URL and is not cached that way. The is the largest display candidate, never a multi-megabyte original: the cap below already stops display files at 1500px, and a native-width master heavier than half a megabyte is re-encoded at the same width when that file is smaller. That href is always the committed original, never a hashed derivative. Every image is wrapped so the print mat's padding sits outside the image (padding on the img itself would shrink it). The wrapper is a.img-full, with the expand mark, when the original is wider than the content column, the page sets linkOriginals (the About squares are CSS crops), or the file on the page is a lighter re-encode of a heavy master. Everything else, including GIFs and files the column already shows at full size, is span.img-mat: the mat, and no zoom affordance. A sits inside that wrapper when a WebP is offered. Animated GIFs pass through untouched. Hugo's image processing flattens them to a single frame. SVG cannot be processed at all. */ -}} {{- $dest := .Destination -}} {{- $alt := .PlainText | default "" -}} {{- $title := .Title | default "" -}} {{- /* Widths worth generating. The content column tops out at $column CSS px, so 1500 covers a 2x display; beyond that nobody sees the extra pixels. $column is also the desktop slot in sizes and the width an original has to beat before we link to it. The inline srcset still stops at $maxWidth either way. */ -}} {{- $column := 750 -}} {{- $ladder := slice 480 $column 1125 -}} {{- $maxWidth := 1500 -}} {{- /* Native-width masters heavier than this are re-encoded for display when the result is actually smaller. The journal photo (~980 KB at 1486px) is the one; every smaller master on the site is left as-is, and a re-encode that grows the file is discarded. */ -}} {{- $heavyBytes := 500000 -}} {{- $isRemote := or (hasPrefix $dest "http://") (hasPrefix $dest "https://") (hasPrefix $dest "//") (hasPrefix $dest "data:") -}} {{- if $isRemote -}} {{- else if hasPrefix $dest "/" -}} {{- /* Absolute path into static/. Kept as a build-time link check: a broken image reference fails CI rather than shipping a 404. */ -}} {{- if not (fileExists (printf "static%s" $dest)) -}} {{- errorf "Image not found: %s (page: %s)" $dest .Page.File.Path -}} {{- end -}} {{- else -}} {{- $image := .Page.Resources.GetMatch $dest -}} {{- if not $image -}} {{- errorf "Image not found: %s (page: %s)" $dest .Page.File.Path -}} {{- end -}} {{- $sub := $image.MediaType.SubType -}} {{- $processable := and (eq $image.ResourceType "image") (not (in (slice "gif" "svg") $sub)) -}} {{- /* The first image on a page is almost always the LCP element: fetch it eagerly and at high priority. -}} {{- $spec := printf "%dx webp q85 photo" .width -}} {{- if not $photo -}} {{- $spec = printf "%dx webp lossless %s" .width $hint -}} {{- end -}} {{- $wr := $base.Resize $spec -}} {{- if ne $wr.Width .width -}} {{- errorf "WebP width %d does not match %d: %s (page: %s)" $wr.Width .width $dest $pagePath -}} {{- end -}} {{- if not $photo -}} {{- $fbSize := $origBytes -}} {{- if not .original }}{{ $fbSize = len .res.Content }}{{ end -}} {{- if ge (len $wr.Content) $fbSize }}{{ $useWebp = false }}{{ end -}} {{- end -}} {{- $webps = $webps | append $wr -}} {{- end -}} {{- $image.Width -}} {{- $md := cond (gt $image.Width 616) 616 $image.Width -}} {{- $sm := cond (gt $image.Width 470) 470 $image.Width -}} {{- /* When the image is narrower than every breakpoint it renders at one fixed width everywhere, and the breakpoint list collapses. */ -}} {{- $sizes := printf "(min-width: 1200px) %dpx, (min-width: 992px) %dpx, (min-width: 768px) %dpx, 83vw" $lg $md $sm -}} {{- if and (eq $lg $md) (eq $md $sm) }}{{ $sizes = printf "(min-width: 768px) %dpx, 83vw" $lg }}{{ end -}} {{- $fallbackSet := slice -}} {{- $webpSet := slice -}} {{- range $i, $c := $cands -}} {{- $wr.RelPermalink $wr.Width) -}} {{- end -}} {{- end -}} {{- /* Wider than the column, an About-style linkOriginals page, or a heavy master we replaced with a lighter same-width file.
